# AI Study Assistant using RAG Concepts

## Overview
AI Study Assistant is a beginner-friendly AI/NLP project that retrieves relevant answers from uploaded PDF notes and study materials. The system uses retrieval-based techniques and text similarity algorithms to search the document and return the most relevant content based on the user's question.

This project demonstrates practical implementation of Retrieval-Augmented Generation (RAG) concepts using Python, TF-IDF vectorization, and cosine similarity.

---

## Problem Statement
Students often struggle to quickly search important concepts from lengthy notes and PDF documents during revision and exam preparation. This project was built to simplify learning by enabling users to ask questions directly from their uploaded study material.

---

## Objectives
- Extract text from PDF documents
- Process and split text into searchable chunks
- Accept natural language questions from users
- Retrieve the most relevant answer from the uploaded notes
- Demonstrate beginner-level AI, NLP, and RAG concepts

## Project Workflow
1. Upload PDF notes or study material
2. Extract text from the PDF document
3. Split the extracted text into smaller chunks
4. Convert text chunks into numerical vectors using TF-IDF
5. Accept user questions as input
6. Compare question similarity with document chunks
7. Retrieve and display the most relevant answer
